# Core loop checklist

Answer each in one sentence. If any answer is "no" or you can't answer, that's
the next thing to build — before any new feature.

## Play
- [ ] Can a new player start the core action within 10 seconds of spawning?
- [ ] Is the core action fun to do 20 times in a row with no rewards?

## Earn
- [ ] Does the player earn something visible within the first 30 seconds?
- [ ] Is it obvious *what* they earned and *why*?

## Upgrade
- [ ] Is the first upgrade affordable within ~2 minutes?
- [ ] Does the upgrade visibly change the play step (faster, bigger, more)?
- [ ] Can the player see the *next* upgrade and its cost at all times?

## Repeat
- [ ] After upgrading, is the next goal immediately clear?
- [ ] Is there a reason to return tomorrow (progress persists, timers, dailies)?

## Red flags
- The pitch lists more than one noun before "and then you…"
- Dev time is going into systems players reach after 30+ minutes while D1
  retention is below 15%
- You can't describe the loop in one sentence
